# goProjects

Учебные программы на Go. Репозиторий — один Go-модуль, каждое упражнение — отдельная программа в `cmd`.

```text
goProjects/
├── go.mod
├── README.md
└── cmd/
    ├── hello/
    │   └── main.go
    ├── pass-fail/
    │   └── main.go
    ├── guess-game/
    │   └── main.go
    └── dragon-game/
        ├── main.go
        └── instruction.md
```

## Запуск

Выполняй команды из корня репозитория:

```powershell
go run ./cmd/hello
go run ./cmd/pass-fail
go run ./cmd/guess-game
go run ./cmd/dragon-game
```

Каждая команда запускает одно упражнение. В каждой папке программы используется `package main` и одна функция `main()`.

## Проверка сборки

```powershell
go build ./...
```

Команда проверяет сборку всех программ, не создавая исполняемые файлы в проекте.

## Новые упражнения

Создай папку `cmd/имя-упражнения` и положи в неё `main.go`. Дополнительные файлы этой программы можно размещать рядом с тем же объявлением `package main`.

Папка `internal` понадобится, если появятся отдельные внутренние пакеты, например общий код для нескольких программ. Сейчас весь код упражнений находится в их собственных папках.
