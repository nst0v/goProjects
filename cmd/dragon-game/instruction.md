Задача

Герой атакует дракона ограниченное количество раз.

Пользователь вводит:

Базовый урон героя
Бонус оружия
Броню дракона
Здоровье дракона
Количество доступных атак

Правила боя

Урон обычного удара:

базовый урон + бонус оружия - броня дракона

Дополнительные условия:

урон не может быть меньше 1;
каждый третий удар — критический, его урон умножается на 2;
здоровье дракона не может стать меньше 0;
когда дракон погибает, атаки прекращаются;
после каждого удара программа показывает результат.
Пример

Входные данные:

Базовый урон: 20
Бонус оружия: 7
Броня дракона: 8
Здоровье дракона: 100
Количество атак: 5

Расчёт обычного удара:

20 + 7 - 8 = 19

Пример вывода:

Удар 1: нанесено 19 урона. Здоровье дракона: 81
Удар 2: нанесено 19 урона. Здоровье дракона: 62
Удар 3: КРИТИЧЕСКИЙ УДАР! Нанесено 38 урона. Здоровье дракона: 24
Удар 4: нанесено 19 урона. Здоровье дракона: 5
Удар 5: нанесено 19 урона. Здоровье дракона: 0

Дракон побеждён за 5 ударов!
Обязательные функции
1. Расчёт урона без брони
func calculateRawDamage(baseDamage int, weaponBonus int) int

Пример:

20 + 7 = 27
2. Применение брони
func applyArmor(damage int, armor int) int

Она должна следить, чтобы итоговый урон был не меньше 1.

3. Расчёт конкретного удара
func calculateHitDamage(
    baseDamage int,
    weaponBonus int,
    armor int,
    hitNumber int,
) (damage int, critical bool)

Здесь нужно определить, является ли удар критическим:

hitNumber%3 == 0

Функция возвращает сразу два значения:

damage, critical
4. Атака дракона
func attackDragon(
    dragonHealth int,
    damage int,
) (remainingHealth int, defeated bool)

Функция должна:

вычесть урон;
не позволить здоровью уйти ниже нуля;
вернуть новое здоровье;
вернуть true, если дракон побеждён.

Ограничения

Для первого решения используй только:

переменные;
if;
цикл for;
функции;
fmt.Print, fmt.Printf, fmt.Scan.

Не используй структуры, массивы, срезы и методы. Цель — не просто получить результат, а правильно разделить программу на функции.

Дополнительный уровень

Когда основная версия заработает, добавь лечебное зелье. У героя есть здоровье, а после каждого удара дракон контратакует. Функция лечения:

func usePotion(
    currentHealth int,
    maxHealth int,
    healing int,
) (newHealth int, actuallyHealed int)

Например, если у героя 90 здоровья из 100, а зелье лечит 30, фактически восстановится только 10.
